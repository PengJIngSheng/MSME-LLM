1. INTRODUCTION
============================================================

MSME.AI is an AI workspace assistant designed to help users complete everyday business
and knowledge-work tasks through a chat-based interface.

Instead of switching between many separate tools, users can ask MSME.AI to help with:

- Writing
- Summarizing
- Researching live web information
- Reviewing documents
- Uploading and analyzing files
- Understanding images
- Generating images
- Creating PDF reports
- Creating Word, PowerPoint, and Excel files
- Working with Google Drive
- Drafting and sending Gmail messages
- Creating Google Docs
- Creating Google Sheets
- Creating Google Slides
- Scheduling Google Calendar events
- Creating Google Meet links
- Managing chat history
- Reusing previous files
- Editing and regenerating AI responses

The system is built around a simple idea:

You tell MSME.AI what you need, and the system chooses the most suitable workflow
based on the active mode, your message, uploaded files, connected services, and
conversation context.


============================================================
2. WHAT MSME.AI IS
============================================================

MSME.AI is not only a general chatbot. It is a workspace assistant with multiple
specialized capabilities.

From the user's point of view, MSME.AI can be understood as five assistants in one:

1. A conversational assistant
   It answers questions, writes text, translates, explains ideas, and helps with
   everyday thinking.

2. A research assistant
   It can search live web sources when you need current information.

3. A document assistant
   It can read uploaded files, analyze PDFs, summarize documents, and generate reports.

4. A productivity assistant
   It can create DOCX, PDF, PPTX, and XLSX files.

5. A workspace assistant
   It can connect to Google Workspace services to create documents, upload files,
   send email with confirmation, create spreadsheets, build slide decks, and schedule
   meetings.

MSME.AI is a browser-based application.

5. FIRST-TIME USER WALKTHROUGH
============================================================

If you are using MSME.AI for the first time, follow this recommended path:

Step 1: Open the application.

You will see the main chat interface, usually with a greeting and an input bar.

Step 2: Create an account or log in.

You can use basic guest access for limited testing, but most useful features require
login.

Step 3: Choose your interface language.

Open settings and select English, Chinese, or Bahasa Malaysia.

Step 4: Try a normal chat question.

Example:
"Explain cash flow in simple terms for a small business owner."

Step 5: Try Web mode.

Example:
"Search the latest Malaysia SME grant information and give me sources."

Step 6: Try Agent mode.

Example:
"I want to generate a PDF report from a business summary."

Step 7: Upload a file.

Upload a PDF, Excel file, CSV, or image and ask the assistant to analyze it.

Step 8: Try a connector if needed.

Enable a Google connector only when you need it.

chat area.

10. ACCOUNT ACCESS: GUEST, LOGIN, AND REGISTRATION
============================================================

MSME.AI can be used in different access states.

Guest access:

- Allows limited basic use.
- Does not unlock full history.
- Does not unlock advanced Agent workflows.
- Does not unlock Google connectors.
- May limit uploads or advanced actions.

Logged-in access:

- Saves chat history.
- Enables Agent mode.
- Enables file upload.
- Enables generated file workflows.
- Enables account preferences.
- Enables Google Workspace connectors after authorization.
- Enables account management features.

For serious use, users should log in.


============================================================
11. EMAIL REGISTRATION
============================================================

Use email registration when you want to create a new MSME.AI account.

Procedure:

1. Click "Sign up" or "Register".
2. Enter your email address.
3. Enter a password.
4. Submit the registration form.
5. Check your email inbox for a one-time verification code.
6. Enter the OTP code on the verification page.
7. After successful verification, your account becomes active.

Good password practice:

- Use at least 8 characters.
- Avoid common passwords.
- Avoid using your email address as your password.
- Use a unique password that you do not reuse elsewhere.

If you do not receive the OTP:

- Check your spam folder.
- Confirm that the email address is correct.
- Wait a few minutes.
- Use the resend option if available.


============================================================
12. EMAIL LOGIN
============================================================

Use email login if you already have an account.

Procedure:

1. Click "Sign in".
2. Enter your email.
3. Enter your password.
4. Submit the login form.

If login fails, check:

- Email spelling.
- Password spelling.
- Whether the account has completed OTP verification.
- Whether Caps Lock is on.
- Whether the browser has outdated saved credentials.


============================================================
13. GOOGLE LOGIN
============================================================

Google login allows you to sign in using a Google account.

Important distinction:

Signing in with Google is not the same as authorizing Google Workspace connectors.

Google login:

- Confirms your identity.
- Lets you access your MSME.AI account.

Google Workspace connector authorization:

- Lets MSME.AI perform specific actions such as creating Docs, uploading to Drive,
  or sending Gmail.

If a connector fails even after Google login, open the connector panel and authorize
the required service.


============================================================
14. ACCOUNT VERIFICATION AND OTP
============================================================

OTP means one-time password or one-time verification code.

MSME.AI uses OTP for:

- New account verification
- Email address changes

OTP best practices:

- Enter the code exactly as shown.
- Use the newest code if multiple codes were requested.
- Do not share the code with others.
- Complete verification before the code expires.

If the OTP expires:

- Request a new code.
- Restart the verification process if required.

Normal chat mode is the default mode for everyday AI assistance.

============================================================
19. FAST MODE
============================================================

Fast mode is designed for quick responses without live web search.

Use Fast mode when:

- The answer does not require current information.
- You are asking for writing, editing, summarizing, or explanation.
- You want a faster answer.
- You are working from uploaded context or conversation history.

Examples:

"Rewrite this sentence to sound more professional."

"Give me five product name ideas."

"Explain this accounting concept in simple language."

"Turn this paragraph into a checklist."

Do not rely on Fast mode for:

- Current prices
- Latest policies
- Recent news
- Live company information
- Current government requirements

Use Web mode for those.


============================================================
20. WEB SEARCH MODE
============================================================

Web mode allows MSME.AI to search live web sources before answering.

Use Web mode for:

- Current information
- Latest news
- Government policy updates
- Current prices
- Product comparisons
- Official requirements
- Recently changed rules
- Time-sensitive questions

How to use:

1. Select Web mode from the mode selector.
2. Type your question.
3. Ask for sources if needed.
4. Send the message.
5. Review the source cards.
6. Read the final answer.

Good Web mode prompts:

"Search the latest Malaysia SME grants and include official sources."

"What are the current requirements to register a Sdn Bhd in Malaysia? Prioritize official sources."

"Find the current RON95 petrol price in Malaysia and cite the source."

"Compare the latest business bank accounts for small companies in Malaysia."

Tips:

- Say which country or region you care about.
- Ask for official sources when possible.
- Ask the assistant to state uncertainty if sources conflict.
- Ask for a table if comparing options.


============================================================
21. SOURCE CARDS AND EVIDENCE-BASED ANSWERS
============================================================

When Web mode is used, MSME.AI may show source cards.

Source cards can include:

- Page title
- Website domain
- Link to the source

Use source cards to verify the answer.

Recommended behavior:

- Open important sources before making business decisions.
- Prefer official sources for legal, government, tax, registration, and compliance topics.
- Ask the assistant to search again if the source is not relevant.

Useful follow-up prompts:

"Use only official sources and search again."

"The previous source is not relevant. Try a different query."

"Summarize only what the source says. Do not add unsupported assumptions."

"List which facts are directly supported by sources."

23. AGENT MODE
============================================================

Agent mode is the advanced workspace mode.

Use Agent mode when you want MSME.AI to do work with files, tools, or external
workspace services.

Agent mode is best for:

- PDF analysis
- Report generation
- DOCX generation
- PDF generation
- PPTX generation
- XLSX generation
- Structured data analysis
- Google Workspace actions
- Gmail preparation and sending
- Calendar scheduling
- Meet link creation
- Uploading files to Drive

How to use Agent mode:

1. Log in.
2. Click Agent in the sidebar.
3. Upload a file or choose a skill if needed.
4. Type your task.
5. Send the request.
6. Review the result.

Examples:

"Analyze this PDF and generate a professional report."

"Create a PPTX pitch deck for this business plan."

"Turn the previous answer into a DOCX document."

"Upload the latest generated PDF to Google Drive."

"Send this report to finance@example.com with a short professional email."

Agent mode note:

Agent mode focuses on task execution. If you need live current web information, use
Web mode outside Agent mode first, then bring the result into Agent mode for file or
workspace tasks.


============================================================
24. HOW TO CHOOSE THE CORRECT MODE
============================================================

Use Fast mode when:

- You want quick writing help.
- You need rewriting, translation, summarization, explanation, or brainstorming.
- Your question does not require current information.

Use Web mode when:

- You need latest or current information.
- You need official sources.
- You need current prices, policies, rules, schedules, or news.

Use Agent mode when:

- You are working with files.
- You want to generate documents.
- You want to use Google Workspace.
- You need PDF or spreadsheet analysis.
- You need a multi-step output.

Recommended sequence for complex work:

1. Use Web mode to gather current information.
2. Ask the assistant to summarize findings.
3. Switch to Agent mode.
4. Generate a report, document, spreadsheet, or slides.
5. Use connectors to save or send the output.

When you hover over your own message, action buttons appear below the message.

- Copy

- Edit
  Lets you edit the message and resend it.

- You want a different version of the answer.
- You want to copy text into another document.


============================================================
26. PAUSING, RESUMING, AND REGENERATING RESPONSES
============================================================

Pausing:

When the assistant is generating, the send button changes state. Click it to stop
generation.

Use pause when:

- The assistant is going in the wrong direction.
- The answer is too long.
- You selected the wrong mode.
- You uploaded the wrong file.
- You want to stop and ask again.

Resuming:

If a response was paused or interrupted, use the message action button to resume.

Regenerating:

Use regenerate when:

- You want a different wording.
- The first answer was not good enough.
- You want the assistant to try again.
- You changed context or want a cleaner answer.

Tip:

If the answer is wrong because your prompt was unclear, edit your user message rather
than only regenerating.

============================================================
36. TEMPLATE-BASED PDF GENERATION
============================================================

Template-based PDF generation is useful when you already have a desired report style
or structure.

Recommended workflow:

1. Upload the source data PDF first.
2. Ask the assistant to create a report.
3. When asked about a template, upload the template PDF.
4. The system reads the template layout.
5. The final report is generated using source data, not placeholder template content.

Example:

"This first PDF is the source data. Please analyze it and generate a report. I will
upload a template next."

Then:

"This PDF is the template. Use the structure and layout, but fill it with the source
data."

Important:

Template example text should not be treated as real business data. Always review the
final report before sending it externally.

66. TROUBLESHOOTING
============================================================

Problem: I cannot log in.

Try:

- Check your email and password.
- Make sure your account is verified.
- Try resetting credentials if available.
- Try a different browser.

Problem: I did not receive the OTP.

Try:

- Check spam or junk folder.
- Wait a few minutes.
- Request a new OTP.
- Confirm the email address is correct.

Problem: Agent mode is locked.

Possible reason:

- You are not logged in.

Try:

- Log in.
- Refresh the page.
- Start a new chat.

Problem: Web search returns irrelevant sources.

Try:

- Ask for official sources.
- Specify country or region.
- Ask the assistant to search again.
- Provide better keywords.

Problem: File upload fails.

Try:

- Use a smaller file.
- Check file format.
- Rename the file.
- Try uploading again.

Problem: PDF analysis is poor.

Possible reasons:

- PDF is scanned.
- Text is not selectable.
- Tables are complex.
- File quality is low.

Try:

- Upload a clearer PDF.
- Ask about specific pages.
- Provide additional context.

Problem: Google connector does not work.

Try:

- Make sure you are logged in.
- Link your Google account.
- Enable the specific connector.
- Complete Google authorization.
- Allow pop-ups.

Problem: Gmail did not send.

Check:

- Did you click Confirm Send?
- Is Gmail connector enabled?
- Is the recipient correct?
- Did authorization expire?

Problem: Generated file does not download.

Try:

- Click download again.
- Ask the assistant to regenerate the file.
- Refresh the page.

Problem: The page design looks old after an update.

Try:

- Hard refresh the browser.
- Clear browser cache.
- Open the page in a private window.
