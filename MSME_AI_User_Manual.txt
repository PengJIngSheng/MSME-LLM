1. 这份手册适合谁阅读
============================================================

这份手册是给 MSME.AI 的最终用户阅读的。适合以下角色：

- 公司内部员工
- MSME / SME 业主
- 行政、财务、运营、市场人员
- 需要写文档、查资料、生成文件、分析资料的人
- 需要使用 Google Workspace 自动化的人
- 需要用 AI 协助处理 PDF、表格、图片、报告的人

这不是开发文档，也不是系统部署手册。手册只解释如何使用系统，不解释服务器、部署、代码架构或基础设施细节。


============================================================
2. MSME.AI 是什么
============================================================

MSME.AI 是一个 AI 工作空间助手。它不是普通的聊天机器人，而是把多种办公能力集中到一个聊天界面里：

- 普通 AI 对话
- 联网搜索
- 文件上传与文件理解
- PDF 分析
- 财务数据分析
- 图片理解
- 图片生成
- Word / PDF / PowerPoint / Excel 文件生成
- Google Drive、Gmail、Docs、Sheets、Slides、Calendar、Meet 等连接器
- 聊天历史保存
- 消息复制、编辑、重新生成
- 用户账户与个人设置

你可以把 MSME.AI 理解成一个“可聊天的工作助手”。你用自然语言告诉它要做什么，它会根据当前模式、上传文件、历史上下文和连接器授权来执行对应任务。

3. 使用前须知
============================================================

3.1 AI 回复需要人工检查

MSME.AI 可以帮助你草拟、分析、总结和生成文件，但 AI 回复仍然可能出现错误、遗漏或过度概括。

建议你在以下场景中务必人工检查：

- 法律、税务、合规相关内容
- 财务报表、贷款、投资相关内容
- 公司注册、许可证、政府政策相关内容
- 对外发送的正式邮件
- 客户合同、报价单、正式报告
- 任何会影响真实业务决策的内容

3.2 当前资料优先使用联网搜索

如果你问的是“最新”、“今天”、“现在”、“当前价格”、“当前政策”、“最近更新”等问题，请使用联网搜索模式，并要求系统给出来源。

示例：

“马来西亚现在注册 Sdn Bhd 需要什么条件和费用？请优先引用官方来源。”

3.3 Agent 模式更适合执行任务

普通聊天适合问答、写作和解释。

Agent 模式更适合：

- 分析 PDF
- 生成 PDF、DOCX、PPTX、XLSX
- 使用 Google Workspace
- 处理上传文件
- 进行多步骤办公任务

3.4 Google 连接器需要授权

如果你要让系统读取、创建或发送 Google Workspace 内容，需要先登录账户，并完成对应连接器授权。

4. 第一次打开系统
============================================================

打开 MSME.AI 后，你通常会看到：

- 中间的欢迎语
- 底部输入框
- 左侧侧边栏
- 右上角登录、注册或设置按钮

如果你还没有登录，你可以作为访客体验部分普通聊天功能。访客模式通常会限制高级功能，例如文件上传、Agent 模式、连接器、更多历史记录等。

建议第一次使用时按以下顺序：

1. 注册或登录账户。
2. 设置界面语言。
3. 设置喜欢的界面语言。
4. 先尝试一个普通问题。
5. 再尝试联网搜索。
6. 如果需要上传文件或生成文件，再进入 Agent 模式。

5. 主界面总览
============================================================

5.1 左侧侧边栏

左侧侧边栏用于切换主要功能：

- Chat：开始普通聊天或新对话。
- Search：搜索或查看历史对话。
- Agent：进入高级 Agent 模式。
- History：查看近期聊天历史。
- 底部账户区域：查看当前登录用户、打开账户菜单。
- 收缩按钮：展开或收起侧边栏。

侧边栏收起后，只显示图标，适合在小屏幕或需要更多阅读空间时使用。

5.2 中间聊天区

聊天区显示：

- 用户发出的消息
- AI 回复
- 联网搜索来源卡片
- 思考过程面板
- PDF 下载卡片
- 图片结果卡片
- 生成文件卡片
- Gmail 发送确认卡片
- 错误或提示信息

5.3 底部输入框

底部输入框用于输入问题和任务。常见控件包括：

- “+” 上传菜单
- 输入文本区域
- Fast / Web 模式选择
- Connectors 连接器按钮
- 发送按钮

在 Agent 模式中，上传菜单会显示更多技能选项，例如生成 DOCX、PDF、PPTX、XLSX。

5.4 顶部或账户菜单

账户菜单通常包含：

- 设置
- 语言
- 连接器
- 账户
- 登出

6. 账户、登录与注册
============================================================

6.1 为什么建议登录

登录后可以使用更多功能：

- 保存聊天历史
- 搜索过去对话
- 上传文件
- 使用 Agent 模式
- 使用 Google Workspace 连接器
- 下载或管理生成文件
- 保存语言偏好
- 管理账户资料

6.2 注册新账户

操作步骤：

1. 点击 Sign up / 注册。
2. 输入邮箱和密码。
3. 系统会发送验证码到邮箱。
4. 打开邮箱查看验证码。
5. 在验证页面输入验证码。
6. 验证成功后即可登录使用。

注意事项：

- 验证码有时效。
- 如果验证码过期，可以请求重新发送。
- 请确认邮箱地址输入正确。
- 如果收不到邮件，请检查垃圾邮件文件夹。

6.3 使用邮箱登录

操作步骤：

1. 点击 Sign in / 登录。
2. 输入注册邮箱。
3. 输入密码。
4. 点击登录。

如果提示账号或密码错误，请检查：

- 邮箱大小写和拼写
- 密码是否输入正确
- 账号是否完成邮箱验证

6.4 使用 Google 登录

你可以使用 Google 账号登录系统。Google 登录用于身份认证。

注意：使用 Google 登录不等于已经授权 Google Workspace 连接器。要使用 Gmail、Drive、Docs 等功能，仍需要在连接器中授权对应服务。

6.5 登出账户

打开账户菜单，点击 Logout / 退出登录。

登出后：

- 当前浏览器会退出账户状态。
- 需要重新登录才能继续使用账户相关功能。
- 本地界面可能仍保留一些语言偏好。

7. 语言与个人偏好
============================================================

7.1 支持语言

系统界面支持：

- English
- 中文
- Bahasa Malaysia

AI 通常会根据你的输入语言回答。例如你用中文问，它会倾向用中文答；你用英文问，它会倾向用英文答。

7.2 切换语言

操作步骤：

1. 打开账户或设置菜单。
2. 找到 Language / 语言。
3. 选择 EN、中文或 BM。

7.3 界面显示

系统现在统一使用浅色界面。

设置菜单中保留语言、连接器、套餐和账户相关功能。

7.4 偏好保存

登录用户的部分偏好会同步到账户中。未登录用户的偏好可能只保存在当前浏览器。

8. 普通聊天模式
============================================================

8.1 普通聊天适合什么

普通聊天适合：

- 写作
- 翻译
- 总结
- 解释概念
- 头脑风暴
- 代码帮助
- 商业计划讨论
- 营销文案
- 邮件草稿
- 简单问答

8.2 使用方法

1. 点击侧边栏 Chat。
2. 在底部输入框输入问题。
3. 点击发送按钮，或按 Enter 发送。
4. 等待 AI 回复。

8.3 示例

示例 1：
“帮我写一封给供应商的专业邮件，语气礼貌，内容是询问报价和交货时间。”

示例 2：
“用简单的话解释 cash flow 和 profit 的区别。”

示例 3：
“帮我为一家咖啡店设计一个三个月营销计划。”

示例 4：
“把下面这段英文翻译成中文，并让语气更正式：……”

8.4 普通聊天的注意事项

如果你的问题需要最新资料，请使用 Web 模式。

如果你的问题需要操作文件、生成文件或使用 Google 服务，请使用 Agent 模式。

9. 联网搜索模式
============================================================

9.1 联网搜索是什么

联网搜索模式会先搜索网页资料，再根据搜索结果回答。它适合需要当前信息的问题。

9.2 什么时候应该使用联网搜索

建议在这些问题中使用：

- 今天、现在、最新、最近
- 当前价格、费用、利率
- 政府政策、注册条件、补贴、税务要求
- 公司、产品、服务的最新资料
- 官方公告
- 法规或指南
- 市场新闻

9.3 如何开启 Web 模式

在输入框右侧选择 Fast / Web。

- Fast：普通快速回答。
- Web：联网搜索后回答。

选择 Web 后再发送问题。

9.4 如何要求来源

你可以直接在问题中加入：

- “请给来源”
- “请引用官方来源”
- “请列出参考链接”
- “优先使用政府或官方网页”
- “如果资料不是官方来源，请说明”

9.5 联网搜索示例

示例 1：
“今天马来西亚 RON95 汽油价格是多少？请给来源。”

示例 2：
“马来西亚现在注册 Sdn Bhd 需要什么条件和费用？请优先引用 SSM 官方来源。”

示例 3：
“请查找最近马来西亚 MSME 相关补贴或 grant，有官方链接最好。”

示例 4：
“比较目前三家银行的 SME business account，列出费用、适合对象和来源。”

9.6 来源卡片

联网搜索完成后，回答上方可能会显示来源卡片。来源卡片通常包括：

- 网页标题
- 来源网站域名
- 可点击链接

你可以打开来源自行核对。

9.7 联网搜索的限制

联网搜索依赖网页可访问性和搜索结果质量。可能出现：

- 官方网页没有被搜索到
- 网页内容过期
- 来源内容互相矛盾
- 网页无法读取
- 搜索结果不够相关

如果你发现来源不对，可以追问：

“重新搜索，只使用官方来源。”

或：

“不要使用刚才那个来源，换成政府或机构官网。”

10. Think Mode / 思考模式
============================================================

10.1 Think Mode 是什么

Think Mode 用于复杂问题。开启后，系统可能会显示一个可折叠的思考或过程面板，用来展示任务进度、分析阶段或搜索过程。

10.2 什么时候使用

适合：

- 多步骤规划
- 商业策略比较
- 文件分析
- 数据分析
- 复杂决策
- 需要解释原因的问题

10.3 注意事项

有些模型或模式可能不显示 Think Mode 开关。如果界面没有显示，说明当前配置不支持或不需要这个功能。

11. Agent 模式
============================================================

11.1 Agent 模式是什么

Agent 模式是高级工作模式。它适合让 AI 执行任务，而不仅仅是回答问题。

在 Agent 模式中，系统更关注：

- 上传文件
- 分析 PDF
- 生成文件
- 使用 Google Workspace
- 多步骤任务
- 生成报告
- 处理财务数据

11.2 如何开启 Agent 模式

1. 登录账户。
2. 点击左侧 Agent。
3. 输入任务或上传文件。

如果未登录，系统会提示你先登录。

11.3 Agent 模式与普通聊天的区别

普通聊天：

- 适合问答、解释、写作。
- 更轻量。
- 可以使用 Web 模式。

Agent 模式：

- 适合文件和工具操作。
- 可以使用连接器。
- 可以生成文件。
- 可以处理 PDF 和结构化数据。
- 默认更偏向任务执行。

11.4 Agent 模式示例

示例 1：
“分析这个 PDF，并生成一份专业报告。”

示例 2：
“根据这份销售表，帮我做一个财务分析。”

示例 3：
“生成一份 PPTX pitch deck，主题是我的咖啡店商业计划。”

示例 4：
“把刚才生成的 PDF 上传到 Google Drive。”

示例 5：
“帮我写一封邮件，把这份报告发送给客户。”

12. 消息操作：复制、编辑、重新生成、暂停与继续
============================================================

12.1 用户消息操作

当鼠标悬停在你发送的消息上时，消息下方会出现操作按钮：

- 复制：复制你发送的内容。
- 编辑：修改这条消息并重新发送。

编辑消息时：

- Enter：提交修改并重新发送。
- Shift + Enter：换行。
- Esc：取消编辑。

12.2 AI 消息操作

AI 回复下方可能出现这些按钮：

- 复制：复制回复内容。
- 重新生成：让 AI 重新回答。
- 继续生成：如果上次生成中断，可以继续。
- 点赞：标记回答有帮助。
- 点踩：标记回答不满意。

12.3 暂停生成

AI 正在回答时，发送按钮会变成停止或暂停状态。点击后可以中断当前生成。

适合在以下情况使用：

- AI 回答方向不对
- 回答太长
- 想换一个问题
- 上传错文件或选错模式

12.4 继续生成

如果回答中断或暂停，你可以在消息操作里选择继续生成，让系统从已有内容继续，而不是完全重来。

============================================================

13.1 查看历史

登录后，左侧 History 会显示历史对话。

你可以：

14. 文件上传
============================================================

14.1 支持的文件类型

系统支持多种文件上传，包括：

- PDF
- CSV
- TSV
- Excel 文件
- JSON
- JSONL
- TXT
- Markdown
- 图片文件

14.2 如何上传

1. 点击输入框左侧的 “+”。
2. 选择 Upload file / 上传文件。
3. 选择本地文件。
4. 文件会显示在输入框上方或消息附件区。
5. 输入你想让 AI 做什么。
6. 点击发送。

14.3 上传后如何提问

不要只上传文件，最好同时告诉系统你想要什么结果。

较弱的提问：
“看看这个。”

更好的提问：
“请分析这个 PDF，提取关键数据，列出主要风险，并给出一页总结。”

14.4 上传多个文件

可以一次上传多个文件。请在问题中说明每个文件的用途。

示例：

“第一个文件是销售数据，第二个文件是费用表。请帮我合并分析 2025 年每个月的利润趋势。”

14.5 文件上传注意事项

- 上传文件越清晰，分析效果越好。
- 扫描版 PDF 可能识别效果较差。
- 表格结构混乱会影响分析质量。
- 如果文件很大，处理时间可能更长。
- 涉及机密资料时，请确认你有权限上传。


============================================================
15. 图片上传与图片理解
============================================================

15.1 支持的图片任务

图片理解可以帮助你：

- 描述图片内容
- 提取截图中的文字
- 读取表格截图
- 分析收据、菜单、发票
- 比较两张图片
- 检查 UI 截图问题
- 分析图表趋势
- 识别明显的视觉元素

15.2 如何上传图片

方式一：

1. 点击 “+”。
2. 选择上传图片或文件。
3. 选择图片。
4. 输入问题。
5. 发送。

方式二：

直接复制图片后粘贴到输入框。

15.3 不输入问题时

如果你只上传图片，没有输入问题，系统会默认分析图片内容、提取文字，并指出重要细节。

15.4 图片理解示例

示例 1：
“提取这张收据里的商家名称、日期、金额和税额。”

示例 2：
“这张网页截图哪里看起来不专业？请给 UI 改进建议。”

示例 3：
“请读取这张表格截图，并整理成 Markdown 表格。”

示例 4：
“比较这两张产品图，告诉我哪一张更适合广告。”

15.5 图片理解限制

图片模糊、反光、裁切、分辨率低或文字太小，都会影响结果。


============================================================
16. 图片生成与图片后续修改
============================================================

16.1 可以生成什么

系统可以生成：

- Logo 概念图
- 海报
- 横幅
- 插图
- 图标
- 社交媒体视觉
- 产品概念图
- 网站视觉素材

16.2 图片生成 Prompt 建议

好的图片 Prompt 通常包含：

- 主体是什么

17. PDF Agent：PDF 分析与报告生成
============================================================

17.1 PDF Agent 是什么

PDF Agent 是 Agent 模式里的专业 PDF 工作流。它可以读取上传的 PDF，提取文字和表格，理解文档内容，并生成报告或新的 PDF 文件。

17.2 适合处理的 PDF

- 财务报告
- 年报
- 商业计划书
- 公司资料
- 调研报告
- 学术资料
- 合同或法律文件
- 医疗或技术文件
- 普通说明文档

17.3 基本使用步骤

1. 登录账户。
2. 进入 Agent 模式。
3. 上传 PDF。
4. 输入任务。
5. 等待系统分析。
6. 如果需要，系统会询问是否有模板。
7. 选择直接生成，或上传模板。
8. 下载生成的 PDF。

17.4 直接生成 PDF

如果你没有模板，可以告诉系统：

“没有模板，直接生成专业报告。”

或：

“请根据这份 PDF 生成一份完整商业分析报告，并导出为 PDF。”

17.5 使用模板生成 PDF

如果你有模板，建议流程：

1. 先上传数据源 PDF。
2. 告诉系统你要生成报告。
3. 系统询问模板时，再上传模板 PDF。
4. 系统会读取模板结构。
5. 系统根据源文件内容填充并生成新报告。

注意：模板的占位文字不应该被当成真实业务资料。系统会尽量避免把模板示例内容混入最终报告。

17.6 重新生成 PDF

你可以继续要求修改：

- “重新生成，语气更正式。”
- “加上执行摘要。”
- “增加风险分析。”
- “把报告改成给投资人看的版本。”
- “再生成一版更简洁的 PDF。”

17.7 PDF 下载

生成成功后，聊天区会出现 PDF 下载卡片。点击下载即可保存。

17.8 PDF Agent 的限制

- 扫描版 PDF 可能提取不完整。
- 表格结构太复杂时可能需要人工复核。
- 法律或财务结论必须人工确认。
- 如果源文件信息不足，系统可能会要求补充资料。

31. 如何写出更好的 Prompt
============================================================

31.1 一个好 Prompt 通常包含

- 任务：你要 AI 做什么
- 背景：为什么要做
- 输入：资料、文件、目标对象
- 输出格式：表格、列表、报告、邮件、PPT
- 语言：中文、英文、BM
- 语气：正式、简洁、销售型、老板汇报型
- 限制：字数、来源、不要编造、只用上传文件

31.2 Prompt 结构模板

“请你作为 [角色]，根据 [资料]，为 [目标对象] 完成 [任务]。输出格式为 [格式]，语气 [语气]，请重点关注 [重点]，如果资料不足请先问我。”

31.3 示例

“请你作为 SME 财务顾问，根据我上传的 Excel，帮我分析过去 12 个月的收入、成本、利润和现金流。输出格式为表格加总结，语气专业但容易理解。如果缺少关键字段，请列出来。”

31.4 避免模糊要求

不建议：

“帮我看看。”

建议：

“请帮我分析这份 PDF 的主要结论、关键数据、风险点，并用中文输出一页摘要。”

建议：

- 登录账户
- 刷新页面
- 新建聊天

33.4 文件上传失败

可能原因：

- 文件过大
- 文件格式不支持
- 网络中断
- 文件名或内容异常

建议：

- 换一个较小文件测试
- 转换为常见格式
- 重新上传
- 避免上传损坏文件

33.5 PDF 分析不准确

可能原因：

- PDF 是扫描版
- 表格复杂
- 内容模糊
- 页面顺序混乱

建议：

- 上传可复制文字的 PDF
- 指定页码
- 说明你最关心的内容
- 让系统只分析某一部分

33.6 联网搜索结果不相关

可以追问：

“重新搜索，只使用官方来源。”

“不要使用上一个来源，请换成更权威的网站。”

“请把搜索关键词改成英文再查一次。”

“请限制在马来西亚来源。”

33.7 Google 连接器不能用

检查：

- 是否已登录
- 是否绑定 Google 账号
- 是否启用对应连接器
- 是否完成授权
- 浏览器是否阻止弹窗

33.8 Gmail 没有发送

请确认：

- 是否点击了 Confirm Send
- 收件人是否正确
- Gmail 连接器是否启用
- 授权是否过期

33.9 生成文件打不开

可以尝试：

- 重新下载
- 让系统重新生成
- 换文件名
- 检查文件是否生成完成

33.10 页面样式没更新

可以尝试：

- 强制刷新浏览器
- 清除缓存
- 重新打开页面
- 换无痕窗口测试


============================================================
34. 使用限制与注意事项
============================================================

34.1 AI 不是最终审核人

AI 可以生成建议，但不应替代专业判断。

34.2 官方资料优先

涉及政府、税务、法律、注册、价格、补贴时，应优先查看官方来源。

34.3 文件越清楚，结果越好

清晰 PDF、结构化 Excel、明确列名、清楚图片会提升结果质量。

34.4 不要一次要求太多互相冲突的任务

例如：

“分析 PDF、生成报告、翻译成三种语言、做 PPT、发邮件、创建会议。”

这种任务可以拆成几步：

1. 先分析 PDF。
2. 确认分析结果。
3. 生成报告。
4. 再生成 PPT。
5. 最后发送邮件。

34.5 重要文件需人工检查

生成的 DOCX、PDF、PPTX、XLSX 在正式使用前，请人工检查格式和内容。


============================================================
35. 推荐工作流
============================================================

35.1 做一份 PDF 报告

1. 登录。
2. 开启 Agent 模式。
3. 上传源 PDF 或数据表。
4. 输入：“请分析并生成一份专业 PDF 报告。”
5. 如果有模板，按提示上传模板。
6. 下载生成 PDF。
7. 要求修改或重新生成。

35.2 做一份商业计划 PPT

1. 开启 Agent 模式。
2. 在 Skills 选择 PPTX。
3. 输入业务背景、目标读者和页数。
4. 生成 PPTX。
5. 下载检查。
6. 如需要，导入 Google Slides。

35.3 查最新政策并整理成文档

1. 选择 Web 模式。
2. 输入问题并要求官方来源。
3. 检查来源卡片。
4. 让系统整理成摘要。
5. 进入 Agent 模式。
6. 生成 DOCX 或 PDF。

35.4 分析销售数据

1. 开启 Agent 模式。
2. 上传 CSV 或 Excel。
3. 输入分析目标。
4. 让系统输出趋势、异常、建议。
5. 需要时生成 XLSX 或 PDF。

35.5 发送报告给客户

1. 生成或上传报告。
2. 启用 Gmail 连接器。
3. 输入收件人、主题和语气。
4. 检查邮件预览。
5. 确认发送。

35.6 创建会议

1. 启用 Calendar 或 Meet 连接器。
2. 输入会议标题、日期、时间、时长、参与者。
3. 检查生成结果。
4. 打开 Calendar 或 Meet 链接确认。


============================================================
结束语
============================================================

MSME.AI 最适合被当成一个“工作协作助手”使用。你可以先让它快速生成初稿，再通过追问、上传文件、联网搜索、生成文件和连接器操作，把初稿变成可执行的工作成果。

最好的使用方式是：

- 简单任务直接问。
- 最新资料用 Web。
- 文件和工具任务用 Agent。
- 重要结果人工检查。
- 复杂任务拆成多个步骤。

这样可以最大化准确性、效率和可控性。
